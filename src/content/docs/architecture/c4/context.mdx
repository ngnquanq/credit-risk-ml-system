Level 1 is the view from outside. It names the people who use the platform and the other systems it relies on, and says nothing about what is inside.

| Who | What they do with the platform |
|---|---|
| Applicant | Applies online and tracks the result |
| Loan officer | Enters walk-in applications, adds verification notes |
| Underwriter | Reviews borderline cases and decides them |
| Risk manager | Proposes and approves the decision bands (two people) |
| Auditor | Traces who did what, read-only |
| Data scientist | Trains models and promotes them to serving |
| Platform engineer | Deploys and operates the platform |

## Reading it

- **People on top** are grouped by what they do: put applications in, steer and check decisions, or build and run the platform. The table lists each role.
- **Dashed line** means a dependency, not a user. The public dataset plays two roles at once: the lender's internal history and the external credit bureau. GitHub matters at run time too: promoting a model clones the repository to build it.
- **Not drawn:** anything inside the platform, which is the next level.
