Level 3 only matters for services with internal structure. The rest of the platform is off-the-shelf software, so it stops at level 2. Open a service to see its parts.

<details>
<summary><strong>Loan API</strong>: routes, use cases, domain, adapters</summary>

The FastAPI service is layered: entrypoints call workflows, workflows use ports defined in the domain, and infrastructure adapters (database, Kafka, warehouse) implement those ports.

<Zoom src="L3-API.svg" alt="Loan API components" caption="Loan API components" />
</details>

<details>
<summary><strong>Stream processing</strong>: the PyFlink jobs</summary>

The change-data job derives application features; the bureau job aggregates credit-bureau history.

<Zoom src="L3-Flink.svg" alt="Flink components" caption="PyFlink jobs" />
</details>

<details>
<summary><strong>Bureau and warehouse feature services</strong></summary>

Two Python services look up an applicant in ClickHouse and publish the result to Kafka.

<Zoom src="L3-Bureau-Service.svg" alt="Bureau service components" caption="Bureau service" />
<Zoom src="L3-DWH-Service.svg" alt="Warehouse feature service components" caption="Warehouse feature service" />
</details>
