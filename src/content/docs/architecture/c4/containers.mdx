Level 2 opens the box. A container here is something that runs on its own: a service, a database, a job. Start with the map below, then open the plane you care about.

## Map by plane

<pre class="mermaid">{`flowchart LR
  P[Portals] --> API[Loan API] --> DB[(Database)] --> FE["Change capture<br/>and features"] --> SC["Feature store<br/>and scoring"] --> REC["Decision<br/>recorder"]
  ID[Sign-in] -.-> P
  API --> AUD[(Audit trail)]
  WH[(Warehouse)] --> FE
  WH --> ML["Model<br/>lifecycle"]
  ML -->|promoted model| SC
  REC --> DB
  classDef added fill:#fdecee,stroke:#c8102e,color:#111;
  class P,ID,AUD,REC added;`}</pre>

Red boxes were added by the release-readiness work (sign-in, portals, audit, decision recorder). The rest is the original pipeline. Monitoring and logging sit beside every plane and are left out to keep the map readable.
